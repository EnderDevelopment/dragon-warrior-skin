# DragonWarriorSkin

DragonWarriorSkin is a custom Minecraft skin featuring a youthful male character with a detailed fantasy dragon illustration on his T-shirt. The skin includes a slim upper body with messy dark ash-brown hair, gray-blue eyes, and a loose black T-shirt with a monochrome white-and-gray dragon graphic. The lower body consists of baggy dark charcoal cargo pants and sturdy black boots. This skin is designed for Minecraft Java Edition and is compatible with the classic Steve model.

## Install

1. Download the `DragonWarriorSkin.png` file from the GitHub repository.
2. Open Minecraft and go to the "Skins" tab in the "Options" menu.
3. Click on "Open Skin Folder" to open the skins directory in your file explorer.
4. Copy the downloaded `DragonWarriorSkin.png` file into the skins directory.
5. Go back to Minecraft and select the "DragonWarriorSkin" from the list of available skins.

## Use

1. After installing the skin, select it from the "Skins" tab in the "Options" menu.
2. The skin will be applied to your character in-game.
3. The dragon illustration on the T-shirt will be visible on the front torso of your character.
